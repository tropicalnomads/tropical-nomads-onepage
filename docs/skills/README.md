# Skills

This folder holds short procedures for people working on Tropical Nomads.

- [ticket-delivery.md](ticket-delivery.md) — how an accepted build-plan ticket is delivered. The order is product manager, technical lead, developer, then QA. The owner reviews after QA. Planning docs do not start this sequence.

A file belongs here when the procedure is real. Product decisions stay in the [master plan](../master-plan.md). Package, deploy, and data structure stay in [architecture](../architecture/monorepo-and-data.md). The [documentation index](../README.md) says which folder to use.

The kind of note that can land here later, once the steps are true:

- refreshing the published event list, after that workflow is agreed
- publishing the one-pager
- adding a merch product, after the catalog is data rather than a constant in the page

Those are examples of future titles only. They are not procedures, and this folder does not contain them.

Placeholder skills do not belong here.
