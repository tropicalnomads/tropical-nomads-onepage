# tropical-nomads-web

Next.js shell for a phone or desktop browser. It is not deployed, and it is not www.

The owner asked for this shell to use the one-pager’s design, components, styles, and colors. It imports that Tailwind theme, `globals.css`, the palette, the Outfit font, the logo, and `EmptyState`. It does not keep a second color system.

The four areas come from `tropical-nomads-shared`. This app does not sell tickets, scan codes, or edit stock.
